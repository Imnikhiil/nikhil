# Nikhil Portfolio

Personal portfolio for **Nikhil Kumar** — Product Engineer.

## Stack

- React + TypeScript + Vite
- Framer Motion
- React Router

## Scripts

```bash
npm install
npm run dev      # local server
npm run build    # production build
npm run preview  # preview build
```

## Structure

```
public/           # static files (favicon, CV, OG, robots)
src/
  assets/         # profile + project images
  components/     # layout + UI
  data/           # site content
  hooks/          # motion helpers
  pages/          # routes
  styles/         # global tokens + base CSS
```

Update `site.url` in `src/data/content.ts` after deploy.
